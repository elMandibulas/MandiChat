# MandiChat
Free chat for dating, with no email, phone, or censorship of freedom of expression.

First window you will see is for new profile creating.
Once saved the profile you will see the Discovery Window:

<img src="DiscoveryWindow.png" alt="Discovery Window" width="50%">

Here you will have to clic "Like" or "No" if you want to establish chat with the person proposed by the app. Thiswindow can bealways accessed by clic "Descubrir" button.
